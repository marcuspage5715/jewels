# Jewels

An Android remake of **Flash Columns** — the timed puzzle mode that shipped with
the Sega Genesis version of *Columns*. Dig down through a pre-stacked well and
clear the one flashing jewel as fast as you can.

Built as a single-screen, dependency-free Android app: no game engine, no image
or audio assets, no third-party libraries. The whole game is Java plus a custom
`View` that draws everything on a `Canvas`.

## Install

The pre-built debug APK is in [`apk/jewels-debug.apk`](apk/jewels-debug.apk).

```bash
adb install -r apk/jewels-debug.apk
```

Or copy the APK to the phone and open it (you will need to allow installs from
that file manager / browser once). It is signed with a standard Android debug
key, so it installs alongside nothing else and is not a Play Store build.

Requires Android 7.0 (API 24) or newer. Portrait only.

## Build

Open the folder in Android Studio and press Run, or from the command line:

```bash
./gradlew assembleDebug          # -> app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug           # build and install on a connected device
```

Toolchain: Gradle 8.7, Android Gradle Plugin 8.5.2, JDK 17, compileSdk 34,
minSdk 24. `local.properties` (with `sdk.dir`) is generated by Android Studio.

## How it plays

Jewels fall in a vertical column of three. Line up three or more of the same
colour horizontally, vertically or diagonally and they vanish; anything above
falls into the gap, which can set off further matches in a chain.

In Flash Columns a stack of jewels already fills the bottom of the well and one
jewel flashes. **Clear that jewel to finish the round.** The target always sits
in the bottom row, but its column and colour are picked at random each round —
never the same spot twice in a row — so there is no fixed colour to plan around. The clock runs, the
stack grows taller each round, and the jewels fall faster. If the well fills to
the top and a new column cannot enter, the run ends.

Before you start you can pick:

| Option | Meaning |
| --- | --- |
| **CLASS** | How many jewel colours are in play — Novice (4), Amateur (5), Pro (6). Fewer colours means more matches, but also more accidental ones. |
| **STACK** | Height of the starting stack, 3 to 8 rows. The round number adds to it. |

Your best run (most rounds cleared) and fastest single round are kept between
sessions.

## Controls

The whole screen is one gesture surface — no buttons over the well:

- **Drag left / right** — move the falling column
- **Tap** — rotate the three jewels within the column
- **Drag down** — nudge the column down faster
- **Flick down** — drop it instantly

A faint outline shows where the column will land. Tap anywhere on a card
(round cleared, overflow, paused) to continue.

On the title screen, **SOUND** mutes the effects and **EXIT** closes the app —
the system bars are hidden during play, so that button is the quickest way out.

## Project layout

```
app/src/main/java/com/marcuspage/jewels/
  MainActivity.java   full-screen host, hides the system bars
  GameView.java       game loop, canvas rendering, touch gestures
  Board.java          6x13 well: matching, removal, gravity, chains
  GemPalette.java     the six jewel colours and their shades
  SoundFx.java        generated sound effects (no audio files)
tools/BoardLogicTest.java   plain-JVM tests for the board rules
apk/jewels-debug.apk        installable debug build
```

### Board rules test

`Board.java` has no Android dependencies, so its rules can be tested on a
desktop JVM without an emulator:

```bash
mkdir -p /tmp/jt
javac -d /tmp/jt app/src/main/java/com/marcuspage/jewels/Board.java tools/BoardLogicTest.java
java -cp /tmp/jt BoardLogicTest
```

It covers horizontal, vertical and both diagonal runs, runs longer than three,
simultaneous matches, gravity, chain reactions, target-jewel detection, stack
generation and placement boundaries. 22 checks.

## Notes

- All artwork is drawn in code — the faceted jewels are pre-rendered bitmaps
  generated at runtime, and the icon is drawn from the same palette. Nothing is
  copied from the original game's sprites.
- Sound effects are synthesised as PCM at start-up and played through
  `SoundPool`; there are no audio assets in the APK.
- The app is offline and asks for no permissions at all.
- *Columns* is a trademark of Sega. This is an unaffiliated personal remake of
  one of its game modes, built for private use.
